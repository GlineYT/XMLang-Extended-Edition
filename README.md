 # XML:EE

The XMLang Extended edition, or XML:EE for short is a continuation of the original XMLang:
https://esolangs.org/wiki/XMLang. 
 
This is intended as a continuation of XMLang, and thus, should be compatible with a good chunk of the code.
Regardless, this does extend the language libraries and adds new ones, so XML:EE code is not always compatible
with XMLang code.

# This is the ODINIFICATION branch, the goal is to slowly replace all rust code with odin code, while maintaining the same functionality and robustness
## There are a few guidelines to keep in mind:
1. No feature commits are accepted, those go in  seperate feature branches
2. No bugfixes are accepted, those go in seperate feature branches
3. Once all code has been odinified, it will replace the code in the master branch, at which point rule 1 and 2 will be invalidaded, and the branch closed
4. AI written contributions are allowed, provided they hold themselves to rule 1 and rule 2, do not cause bugs, regressions and follow current best practices.
